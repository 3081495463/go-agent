# Web Development Skill

当用户要求开发网页时：

1. 先分析需求，确定页面包含哪些部分。
2. 规划页面结构与配色。
3. 使用 HTML 和 CSS 实现，保证响应式布局。
4. 将文件写入 workspace 目录（file 工具的 path 相对工作区根，不要再重复写 workspace/ 前缀）。
5. 调用文件工具后检查写入结果。
6. 需要预览时先用 shell 的 serve 动作启动静态服务，再用 shell 的 open 动作在默认浏览器打开页面；浏览器 MCP 工具用于检查排版与报错，默认不调用截图工具，优先用页面快照、控制台消息等文本信息。
7. 向用户说明生成的文件位置。
